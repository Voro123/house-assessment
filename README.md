# 住哪儿 · 租房评估

一个面向手机现场使用的租房看房记录工具。所有项目都允许留空，输入后自动保存，适合一边看房一边逐项记录。

## 已实现

- 房源列表、搜索、草稿/完成状态筛选
- 租金、押金、管理费、户型、面积、楼层、入住日期等基础信息
- 浏览器自动定位、地址反查、手动输入地址、OpenStreetMap 地图选点
- 联系人、电话、联系人类型和联系备注
- 调用手机相机或相册，最多保存 12 张压缩照片
- 手机方向传感器判断朝向，并支持手动修正
- 阳台、空调能耗、洗衣机、取暖、做饭、宠物、停车及水电计费
- 水质、空间、插座、噪音、采光、通风、防潮、厨卫、收纳、信号、安全、通勤、配套、隐私、物业和卫生等 17 项可选评分
- 每个评分项目可单独添加观察备注
- 优点、风险、待确认问题和其他记录
- IndexedDB 本地持久化、自动保存、初次记录时间和最后编辑时间
- 随时编辑、删除、导入和导出 JSON 备份
- 移动端优先响应式界面与 Web App manifest

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 使用说明

定位、指南针和相机通常要求页面通过 HTTPS 打开。地址反查和地图瓦片依赖网络；即使地址反查失败，坐标和手动地址录入仍可正常使用。

当前版本没有后端，房源数据和照片只存放在当前浏览器的 IndexedDB 中。清除浏览器站点数据前，请先使用“导出备份”。
